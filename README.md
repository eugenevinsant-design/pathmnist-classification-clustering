# Task 3 — PathMNIST: классификация и кластеризация

## 3.1 — CNN с учителем

Гистология — пространственная текстура, поэтому свёрточная сеть, а не полносвязная. 4 блока `Conv → BN → ReLU → Conv → BN → ReLU → MaxPool` (каналы 32→64→128→192), голова `AdaptiveAvgPool2d → Linear(192,128) → ReLU → Dropout(0.4) → Linear(128,9)`, ~867 тыс. параметров — компактно под 28×28, чтобы не переобучиться.

Решения по данным: аугментация только геометрическая (ткани не меняют класс от поворота), нормализация считается по train (без утечки теста), стратифицированный split 80/20 (классы несбалансированы). AdamW + `ReduceLROnPlateau` + early stopping; метрика macro F1, потому что классы неравномерны.

Результат: val accuracy ≈ 0.954, macro F1 ≈ 0.94.

## 3.2 — от автоэнкодера к supervised-эмбеддингам

Сначала стандартный unsupervised-путь: `ConvAutoencoder` (латент 64, denoising) → `StandardScaler → PCA(32, whiten) → KMeans`. Не сработало: латент оптимизирован на восстановление пикселей, а не на разделимость тканей. Метрики — silhouette ≈ −0.005, ARI ≈ 0.18, NMI ≈ 0.27, плюс вырожденный кластер из 3 объектов.

Вывод: для кластеризации решают признаки, а не алгоритм. Взяли 192-мерный латент supervised-CNN из 3.1 (она различает классы с ~95% точности, значит структура в эмбеддинге есть). KMeans обучается без меток на train 3.2 — условие соблюдено.

Пайплайн: загрузка `best_task3_1_model.pth` → латент из `AdaptiveAvgPool2d` → `StandardScaler` (fit только на train 3.2) → `KMeans(n_init=50, random_state=42)`. Без PCA и whitening: стандартизация уже снимает масштаб, whitening на плоских компонентах усиливает шум.

Результат: silhouette ≈ 0.534, ARI ≈ 0.941, NMI ≈ 0.937, все 9 кластеров в train и тесте.

## Итог

3.1 подтвердила пригодность архитектуры. 3.2 показала, что смена эмбеддингов подняла ARI с 0.18 до 0.94 без изменения KMeans.
